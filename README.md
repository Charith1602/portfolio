# Charith Rage: portfolio

Interactive portfolio: skills globe, knowledge graph, filterable projects, case-study pages, light and dark themes.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

Edit content in `src/content/*.json` (see `CLAUDE.md` for the content model and contribution rules). Add a portrait at `public/photo.jpg`.

Deploy: import the repo in Vercel (zero config).
